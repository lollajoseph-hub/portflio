# Omolola Joseph · portfolio

A 16:9 animated portfolio deck. Slides slide sideways; project slides flip to show the case study.

- `index.html`: every slide and all the text
- `styles.css`: the look (landscape stage plus portrait reflow)
- `app.js`: the deck engine (scaling, transitions, keys/swipe/wheel, video, interactives)
- `media/`: launch films, posters and images from the earlier portfolio

No build step. Open `index.html` locally, or serve the folder with any static host.
